Funcionamento do site

Este site apresenta a loja e sua seleção. Não oferece contas, pagamentos ou formulários para coleta de dados pessoais. O código não utiliza cookies, pixels de publicidade, análise de audiência ou armazenamento local para acompanhar visitantes.

Hospedagem e registros técnicos

O site público atual está hospedado no GitHub Pages. O GitHub registra o endereço IP para segurança; não informa à Ótica Pupila um prazo específico de guarda desses registros. Localização dos servidores não informada à Ótica Pupila pelo provedor.

Atendimento pelo WhatsApp

Os botões de WhatsApp abrem o serviço com uma mensagem sugerida sobre o produto ou a página consultada. Você pode revisar a mensagem antes de enviá-la. Ao conversar com a loja, você pode compartilhar nome, telefone, fotos, receitas de óculos e outras informações para receber atendimento e consultar produtos. Receitas podem conter dados de saúde. As conversas são guardadas pela loja sem prazo de exclusão previamente definido. O WhatsApp também trata dados conforme suas próprias condições.

Mapa e rotas

O Google fornece os mapas incorporados nas páginas inicial e de contato. Os atalhos de localização abrem o Google Maps para traçar a rota até a loja. O Google pode usar informações do navegador ou a localização do dispositivo, conforme as permissões que você conceder.

Seus dados e contato

Para solicitar informações, acesso, correção ou exclusão de dados pessoais, escreva para oticapupila.adm@gmail.com. A loja avaliará o pedido e eventuais obrigações legais de conservação.
